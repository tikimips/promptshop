AI Photobooth — System Architecture

Build your own AI photobooth

One copy-paste prompt. About an hour. No coding experience needed. Guests step up, pick how many people, the camera counts down, and an AI turns them into a themed photo ready to print.

1 · What you need

A computer with Chrome and a webcam, a free GitHub account, a free Vercel account (that's where your booth will live on the internet), and your own Google Gemini API key. Budget about an hour end to end, and about 7 cents per photo once you're live.

2 · Copy the master prompt

Fill in the three blanks at the top — [YOUR EVENT NAME], [YOUR THEME], [PICK A SIMPLE PASSWORD] — then paste the whole thing into an AI coding assistant (Claude, ChatGPT, Cursor, whatever you use) and follow its lead.

EVENT NAME: [YOUR EVENT NAME]
THEME: [YOUR THEME — e.g. "superheroes in a city", "80s sci-fi", "pirates at sea"]
PASSWORD: [PICK A SIMPLE PASSWORD]

You are going to build me a complete AI photobooth web app and walk me through
deploying it. I am a beginner — give me one step at a time and never assume I
know developer tools.

WHAT TO BUILD
A Next.js app deployed on Vercel with one photobooth page and one API route.

The booth page, full screen and touch friendly:
1. Attract screen showing the EVENT NAME and a big pulsing GO — tap anywhere
   to start.
2. A "How many people?" screen with big buttons 1 through 5.
3. Live webcam view (front camera, mirrored) with one dashed face oval per
   person, side by side. A banner says "Put your face in the oval." After
   about 4 seconds (6.5 for groups), a big 3-2-1 countdown, then a white
   flash and capture.
4. Crop each oval (plus generous margin) out of the frame as its own JPEG.
5. Show a "creating your photo…" screen while the crops are sent to the
   API route.
6. The API route keeps my Gemini API key in an environment variable named
   GEMINI_API_KEY — never in the page code — and calls Google's model
   "gemini-3.1-flash-image" (fall back to "gemini-2.5-flash-image") via the
   REST generateContent endpoint with: one text prompt, plus each face crop
   as inline_data, generationConfig responseModalities ["TEXT","IMAGE"] and
   imageConfig aspectRatio "3:2". Return the generated image as base64 JSON.
7. The text prompt must say: a photorealistic, cinematic photo of the
   person/people in the attached photo(s) placed in THEME; the image must
   contain exactly N people, one per attached photo, each preserving that
   person's real facial features, expression, skin tone, age, gender and
   hair exactly; blended seamlessly like one professionally shot photograph,
   not a collage; every face at least 5% away from every edge; no text or
   watermarks; faces never covered by masks or helmets.
8. Preview screen: show the photo for 20 seconds with a countdown circle,
   Portrait / Landscape toggle buttons (portrait = face-centered crop to
   2:3), and a big Print button. Print (or the timer ending) downloads the
   photo and shows "Your photo is ready at the printing station," then
   auto-returns to the start screen.
9. Details that matter: request the camera once and keep the stream for the
   whole session so the browser asks permission only once; ask for
   1920x1080; if generation fails, silently retry once, then show a friendly
   try-again screen; auto-reset to the start screen after 90 seconds idle;
   add a password gate using PASSWORD (middleware + a simple cookie) so
   only my event can use it.

DEPLOYMENT
Create a GitHub repo, connect it to a free Vercel account, and show me
exactly where in Vercel to paste my own Gemini API key as the
GEMINI_API_KEY environment variable (Settings → Environment Variables →
Production → then Redeploy). I will get my own key from
aistudio.google.com — remind me it bills my account about 7 cents per
photo and to set a monthly spend cap.

Build everything first, then give me the deploy steps one at a time.

3 · Your own Gemini API key

The AI photos are generated by Google's Gemini image model, and it needs your own API key — get one at aistudio.google.com. The image models have no free tier, so the key must belong to an account with billing enabled, and every photo bills roughly $0.07 to your card.

Your key is a secret. Never paste it into a web page, a prompt, or anything public — anyone who has it can spend your money. The master prompt above deliberately makes your AI assistant store it as a private environment variable on Vercel and shows you exactly where to paste it. While you're in AI Studio, set a monthly spend cap so a runaway booth hits a wall instead of your wallet.

4 · Theme it

Once your booth works, paste any of these follow-up prompts to reskin it — or write your own in the same shape.

Sports teams

Update my photobooth: before the "How many people?" screen, add a team
picker grid. Each team's generation prompt places the people in that
team's authentic uniform inside their home stadium, photorealistic, packed
crowd, dramatic lighting — and helmets always off or under an arm so faces
stay fully visible. My teams: [LIST YOUR TEAMS].

Movies

Update my photobooth: add a movie picker grid before the "How many
people?" screen. Each movie renders the people inside that film's world
and art style — animated films become stylized cartoon versions that keep
each real face recognizable; live-action films are photorealistic movie
stills with that film's lighting and grain. My movies: [LIST YOUR MOVIES].

Anime

Update my photobooth: skip pickers. Each photo randomly combines one
character-design inspiration and one atmosphere from lists I give you,
converting everyone into anime characters with sharp line work, vibrant
cel-shading and large expressive eyes while preserving real faces, hair
and ages. Inspirations: [LIST SHOWS/CHARACTERS]. Atmospheres: [LIST
SETTINGS].

Superheroes

Update my photobooth: skip pickers. Each photo randomly picks a plain,
completely unbranded superhero costume (absolutely no logos or emblems), a
city atmosphere ranging from dark rainy noir to bright sunny morning, and
a heroic action pose. In group shots every person gets a different
costume. Faces are never masked.

80's Synthwave

Update my photobooth: one fixed style for every photo — a retro 1980s
synthwave album cover. The people wear 80s outfits (denim jackets, aviators,
big hair welcome), lit by hot pink and electric blue neon against a sunset
grid horizon with chrome reflections, palm silhouettes and a giant retro
sun, VHS film grain. Faces stay photorealistic and fully recognizable.
